# Plugin.Maui.HttpForge.NewtonsoftJson

Optional [Newtonsoft.Json](https://www.nuget.org/packages/Newtonsoft.Json) serializer for [Plugin.Maui.HttpForge](https://www.nuget.org/packages/Plugin.Maui.HttpForge). The core package stays on System.Text.Json.

```csharp
settings.ContentSerializer = new NewtonsoftJsonContentSerializer();
```
